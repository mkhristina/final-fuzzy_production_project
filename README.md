# Интеллектуальная нечёткая система оценки производственного риска цеха

## 1. Описание проекта

Проект предназначен для оценки производственного риска цеха на основе методов нечёткой логики. Реализованы две модели нечёткого вывода: Мамдани и Сугено. Результаты моделей можно сравнивать между собой и с экспертной оценкой риска.

Дополнительно проект включает анализ производственных данных, визуализацию, кластеризацию методом Fuzzy C-Means и оптимизацию параметров функций принадлежности.

## 2. Цель проекта

Разработать интеллектуальную систему, которая оценивает уровень производственного риска по показателям работы цеха, объясняет полученный результат с помощью базы правил и позволяет исследовать закономерности в производственных данных.

## 3. Используемые показатели

Для оценки риска используются следующие входные переменные:

- `utilization` — загрузка оборудования;
- `defect_rate` — доля брака;
- `downtime_pct` — доля времени простоя;
- `overdue_orders` — количество просроченных заказов;
- `staff_availability` — доступность персонала;
- `energy_overrun` — превышение энергопотребления.

Целевая переменная `expert_risk` представляет собой синтетическую экспертную оценку риска в диапазоне от 0 до 100.

## 4. Реализованные методы

### Нечёткая логика

- Модель Мамдани с использованием библиотеки `scikit-fuzzy`.
- Модель Сугено с независимой реализацией расчёта.
- Треугольные и трапециевидные функции принадлежности.
- База экспертных правил.
- Определение итоговой категории риска и объяснение результата.

Категории риска: низкий, умеренный, высокий и критический.

### Анализ данных и визуализация

Проект включает анализ распределений показателей, корреляций и производственных сценариев, а также графики функций принадлежности и сравнения результатов нечётких моделей.

### Кластеризация

Метод Fuzzy C-Means используется для выявления групп производственных наблюдений. Результаты сохраняются в каталоге `results/`.

### Оптимизация

Предусмотрен модуль оптимизации параметров функций принадлежности с использованием методов библиотеки `scipy`.

## 6. Установка и запуск

Требуется установленный Python и `pip`.

Установите зависимости:

```bash
python -m pip install -r requirements.txt
```

Запустите основной модуль:

```bash
python main.py
```

Если требуется открыть графический интерфейс Streamlit, запустите:

```bash
python -m streamlit run src/gui.py
```

После запуска Streamlit откройте адрес, указанный в терминале, обычно `http://localhost:8501`.

## 7. Запуск тестов

Для запуска автоматических тестов выполните:

```bash
python -m pytest -q
```

Тесты проверяют работу подготовки данных и нечётких моделей.

## 8. Результаты

Сгенерированные данные находятся в `data/production.csv`. Результаты анализа, кластеризации и сравнения моделей сохраняются в каталоге `results/`, а графики — в `results/plots/`.

## 9. Ограничения

Набор данных является синтетическим и генерируется программно с фиксированным начальным значением генератора случайных чисел. Поэтому `expert_risk` не является результатом реальной экспертной оценки или фактических производственных измерений.

Качество моделей следует оценивать с учётом этого ограничения. Результаты предназначены для учебного исследования методов нечёткой логики и не должны использоваться как единственное основание для реальных решений по промышленной безопасности.
